Variáveis e Escopo variável

Como qualquer linguagem de programação, a GML usa variáveis como unidade básica para a maioria das operações de programação. As variáveis são usadas para armazenar informações na memória dos dispositivos para uso posterior (ou instantâneo), e lhes é dado um nome para que você possa consultá-las nas funções runtime e script. Uma variável no GML pode armazenar muitas tipos de dadosComo um número real (ex: 100, 2.456575, -56 etc...), um string (ex: "Olá mundo!"), um número inteiro (ex: 1, 556, -7), ou um booleano (true ou false), assim como outras coisas:

var _num = 126.4545;
var _str = "Hello World";
new_num = _num * 100;
global.my_string = _str + " I said";

Você também pode usar variáveis para manter os valores retornados de funções, por exemplo:

var _id = instance_nearest(x, y, obj_Tree);
root = sqrt(1000);
global.str = string_upper("Hello World");

Portanto, uma variável é algo que podemos nomear e usar para armazenar um valor para uso posterior em uma ou mais operações. Um grande exemplo de "mundo real" de uma variável é pi 𝜋 . .. é uma variável que todos conhecem e que detém o valor 3,14159265(etc...). Por que a temos em nosso idioma? Bem, é muito mais fácil dizer a alguém "pi" do que "três ponto um quatro um cinco cinco nove dois seis cinco"! Nomear coisas assim torna a vida muito mais simples e também significa que se o valor dessa variável alguma vez mudar, não temos que mudar o número em todo lugar, pois o nome da variável ainda é o mesmo.

Ao formar variáveis no GML ele deve ter um nome que comece com uma letra ou o símbolo de sublinhado "_" e pode conter apenas letras, números e o símbolo de sublinhado "_" com um comprimento máximo de 64 símbolos. Portanto, variáveis válidas são coisas como fish, foo_bar, num1, ou _str, enquanto variáveis inválidas seriam 6fish, foo bar, ou *num.

Agora, em muitas linguagens de programação, você precisa criar uma "atribuição" variável antes de poder usá-la. Isto significa basicamente que você diz ao computador o nome que deseja usar para a variável e lhe atribui um valor inicial. A variável recebe então um lugar na memória para armazenar o valor ou realizar operações sobre ela. A atribuição de uma variável toma a forma de:

<variable> = <expression>;

Uma expressão pode ser um valor simples mas também pode ser mais complicada, portanto, em vez de atribuir um valor a uma variável, pode-se também acrescentar um valor ao valor atual da variável usando +=, por exemplo:

a = 100;   // Assigning a simple value
b = 200;
c = 300;
a += b;    // Assigning with operation
a = b + c; // Assigning with expression

NOTA O GameMaker Language também aceitará ":=" para tarefas, embora esta não seja a maneira mais comum de fazê-lo:

<variable> := <expression>;

Da mesma forma, você pode subtrair usando -=, multiplicar usando *=, dividir usando /=, ou usar operadores bitwise usando |=, &=, ou ^=. Você também pode adicionar ou subtrair um de um valor usando ++, --. Para mais informações, consulte a seção sobre Expressões e Operadores.

Observe que você não pode fazer o seguinte (ou qualquer variação):

a = b = c = 4;

E ao invés disso, deve ser feito como:

a = 4;
b = 4;
c = 4;

As atribuições de variáveis mostradas acima são todas variáveis de instância , porém existem na verdade três outras categorias de variáveis principais quando você programa com o GameMaker e cada uma tem seu próprio escopo (que pode ser considerado como sua área de operação, ou alcance). Os diferentes tipos de variáveis e seu escopo estão todos delineados nas páginas seguintes:

  • Variáveis locais
  • Variáveis de instância
  • Variáveis globais
  • Constantes

O GameMaker Language também tem múltiplas variáveis embutidas que podem ter qualquer um dos escopos acima mencionados (exceto local). Estas variáveis são especiais, pois são incluídas por padrão como parte do objects e do rooms no mundo do jogo. Algumas variáveis globais incorporadas estão listadas na seção mencionada acima, e as diferentes partes do manual para sprites, rooms, objects, etc... também descrevem as variáveis incorporadas disponíveis em cada caso. Exemplos de tais variáveis de instância incorporadas seriam:

  • sprite_index
  • path_scale
  • speed

E exemplos de variáveis globais incorporadas seriam:

  • view_xport
  • GM_version
  • room

A maioria das variáveis embutidas pode ser alterada e definida como outras variáveis, e algumas podem até ser arrays, só que você não precisa defini-las para criá-las como se fosse uma variável normal, pois elas já serão inicializadas para um valor padrão.
